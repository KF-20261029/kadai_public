# ペン収納用LoRA

SO-101用に調整されたπ0.5 `dongyoonkim/so101-pi05-base` に、ペン収納を追加学習した重みです。ベースモデルはリビジョン `56325bafcca9ec3155b8bfdf655be7df17e7f09f` を使いました。

## 学習

タスクと教師データはCodexを用いて作成しました。物体位置と逆運動学から得た成功デモ55試行・99,000フレームを用い、LoRAで30,000ステップの模倣学習を行いました。ベースモデルの重みは固定し、LoRAの重みだけを更新しました。

- 入力：上方・手首カメラのRGB画像、６関節の状態、タスク指示。
- 出力：６関節の位置指令50個からなるアクションチャンク。実行は30 Hz。
- LoRA：rank 16、alpha 16、dropout 0。
- バッチサイズ：８。最適化：AdamW。最大学習率：0.00005。
- 学習率：1,000ステップのウォームアップ後、cosineで減衰。
- 指示：`Grab pens and place into pen holder`。

物体位置は教師データの生成だけに使い、モデルへは入力していません。教師データ本体の代わりに、[生成コードと手順](../../teacher/README.md)を収録しています。学習設定と実行方法は[LoRAの学習](../../training/README.md)に記載しています。

## ファイル

- `lora_adapters/adapter_model.safetensors`：ペン収納用に学習したLoRA。Git LFSで配布。
- `lora_adapters/adapter_config.json`：LoRAの構成。
- `normalize_buffers.pt`：タスク用の状態・動作の正規化統計。推論時に復元が必要。
- `config.json`：保存時のモデル構成。
- `CHECKSUMS.json`：配布ファイルのSHA-256。

重みの読み込みにはベースモデルと元のPaliGemmaトークナイザが別途必要です。取得方法は[ルートREADMEのセットアップ](../../README.md#セットアップ)を参照してください。

## 評価結果

同じ10配置で評価した結果は次のとおりです。両モデルに共通のタスク用正規化統計を使用しました。

| モデル | 推論中のシミュレーション | 成功数 |
| --- | --- | --- |
| ベースモデル | 一時停止 | 10回中０回成功 |
| 追加学習後 | 一時停止 | 10回中２回成功 |
| 追加学習後 | 継続 | 10回中１回成功 |

試行別の成否は[集計結果](../../docs/results)に収録しています。

## 制約

訓練用49試行・検証用６試行に分ける設定が読み込み時に反映されず、両方に全55試行が読み込まれました。そのため、独立した検証データによる学習時評価は得られていません。学習後の評価には、教師データ収集とは別のseedの10配置を使いました。実機動作は評価していません。
